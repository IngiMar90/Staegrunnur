# Grunnstærðfræði — sameinuð útgáfa

Æfingar þessa verkefnis hafa verið sameinaðar við Grunnstae.

**Opna leikinn:** https://ingimar90.github.io/Grunnstae/

Gömlu tenglarnir vísa á sameinuðu útgáfuna. Eldri kóðinn er varðveittur í git-sögunni og öðrum upprunalegum skrám. Niðurstöður úr localStorage eru fluttar inn við fyrstu opnun sameinaða leiksins í sama vafra á sama GitHub Pages uppruna.
